# Kalonet

Kalonet is a mobile nutrition and fitness tracking application built with Flutter, FastAPI, and PostgreSQL.

The project is being developed as a portfolio-focused, production-style learning project.

## Planned capabilities

The MVP includes:

- Email and password authentication
- Password reset
- User onboarding
- Calorie and macronutrient targets
- Meal logging
- AI-assisted meal-photo proposals and manual meal logging
- Water tracking
- Step tracking
- Activity tracking
- Dashboard summaries
- Profile and settings
- Account deletion

Later phases include gamification, recipes, subscription UI, and Gemini-assisted features.
